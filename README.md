
# OnlineChess

OnlineChess is a cross-platform chess application with
real-time online multiplayer and AI-powered game analysis.

## Project Overview

The project aims to develop a chess application that allows
users to play chess online, manage matches, and analyze
their games with the help of a chess engine.

## Main Features

- User registration and authentication
- Chessboard and legal move validation
- Real-time online multiplayer
- Matchmaking and game rooms
- Match history
- AI-powered chess analysis

## Project Structure

- `frontend/`: User interface
- `backend/`: API and business logic
- `chess-engine/`: Chess engine integration
- `database/`: Database scripts and design
- `docs/`: Project documentation and diagrams
- `tests/`: Test cases and automated tests
